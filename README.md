# ChurnGuard

Telco customer churn classification and interpretation dashboard.

## Project structure

```text
src/churnguard/
    data/              Data loading and validation
    features/          Feature preparation and transformations
    training/          Model training and parameter selection
    evaluation/        Validation, metrics and model comparisons
    interpretation/    Model explanations
app/                   Prediction and dashboard interface
tests/
    unit/              Component tests
    integration/       Pipeline and application tests
notebooks/             Exploratory analysis and experiments
```

These folders currently contain placeholders; functionality will be added
incrementally.
